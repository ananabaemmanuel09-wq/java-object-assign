This directory is designated for saving genuine terminal screenshots generated from running each of the 8 assignment files.

Capture actual screenshots of the terminal when executing each JavaScript file with Node.js and save them here using the following exact filenames:

- `level1_q02.png` — Output of `node level1/question02_update_product.js`
- `level1_q03.png` — Output of `node level1/question03_add_delete_properties.js`
- `level2_q01.png` — Output of `node level2/question01_rectangle_calculator.js`
- `level2_q04.png` — Output of `node level2/question04_order_total.js`
- `level3_q03.png` — Output of `node level3/question03_merge_settings.js`
- `level3_q04.png` — Output of `node level3/question04_shopping_cart.js`

> **Note:** As instructed in the project rules, placeholder, fake, or synthetic image files are strictly prohibited. Save only actual, genuine screenshots captured during your own terminal execution.
